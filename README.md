# 🦊 Denkzauber · Klasse 4

An **offline maths practice app** for a 4th-grader (German school, *Klasse 4*) with a playful, calm reward system. One static web page: no server, no accounts, no tracking. The interface is in **German**.

**▶ Try it:** <https://vipinmohan11.github.io/Mathe-Abenteuer/> (installable PWA – in Chrome choose *Add to Home screen*).

## What it offers

- **Meine Hefte:** exercises for the workbook chapters (generated by code – no workbook content is copied), plus *Kopfrechnen* (times tables, mental and written arithmetic), a *Fehler-Heft* for mistakes and a timed *Mini-Test*.
- **Rewards:** coins, stars, cards and trophies, with short animations. Coins are spent in the shop.
- **Ideenwerkstatt:** *Meine Musik*, *Geschichte* and a music-notation notebook. A floating **Notizbuch** bubble is available on every screen.
- **Lustige Karten:** fun facts and collectable cards.
- **Europa Entdecker** and **Meine Weltreise:** geography quiz and a travel passport.
- **Parents' area (PIN):** daily homework gate, time limits, per-area lock/unlock, backup and restore.

Progress is stored only on the device (`localStorage`); export a backup from the parents' area.

## Develop

```bash
npm install          # test dependencies (jsdom)
python3 build.py     # builds dist/Mathe-Abenteuer_Klasse4.html and the PWA files
npm test             # build + generator and flow tests
npm run test:all     # plus the Playwright suites (python3, playwright, Chromium)
```

Source lives in `src/`; `build.py` concatenates it into one HTML file. Detailed notes: [`docs/FEATURES.md`](docs/FEATURES.md), [`HANDOFF.md`](HANDOFF.md).
